# CouchAxis 程序功能说明

> 文档版本：0.1.0-current
> 最后核对：2026-08-08
> 适用平台：Windows 10 / 11

## 1. 产品概述

CouchAxis 是一款本地独立运行、手柄优先的媒体文件浏览与播放应用。它面向电视、大屏和沙发观看场景，直接展示 Windows 磁盘与目录，不要求用户先扫描媒体库，也不依赖服务器、账户或在线服务。

当前版本支持三类本地媒体：

- 视频：播放、字幕、截图、倍速和专注模式。
- 音乐：递归播放队列、播放模式、内置歌词、内置封面、频谱和黑屏播放。
- 图片：完整适应窗口、缩放、平移、旋转、比例锁定、漫画起点和专注模式。

## 2. 产品边界

### 2.1 当前提供

- 枚举 Windows 固定磁盘和可移动磁盘。
- 直接浏览真实目录结构。
- 只显示文件夹和可识别的媒体文件。
- 使用手柄完成主要浏览、设置和播放操作。
- 收藏常用文件夹并记住上次浏览位置。
- 绑定并从侧栏启动本机 Windows 应用程序。
- 自动续播最近观看的三个视频。
- 中文、英文界面。
- 本地偏好持久化。
- Windows 独立 EXE、NSIS 安装程序和 MSI 安装包。

### 2.2 明确不提供

- 媒体库扫描、海报墙或影视信息刮削。
- 在线播放、在线字幕或自动下载字幕。
- NAS、SMB 或其他网络共享集成。
- 文件复制、移动、重命名或删除。
- 用户账户、云同步或远程控制服务。

### 2.3 本地写入范围

CouchAxis 浏览媒体时不会修改源文件。应用只写入以下内容：

- 应用偏好文件，包括上次路径、收藏夹、应用绑定、最近三个视频的播放进度和设置。
- 用户主动截取的视频画面 PNG 文件。

## 3. 快速使用流程

1. 启动 CouchAxis。
2. 从左侧选择磁盘、收藏夹，或启动已绑定的应用程序。
3. 使用左摇杆或方向键移动选择。
4. 按确认键进入文件夹或打开媒体。
5. 在播放或查看页面使用页面专属按键。
6. 同时按左右扳机显示当前页面的手柄说明。
7. 按返回键关闭媒体或返回上级目录。

应用默认以全屏窗口启动，并根据“初始界面”设置打开上次目录、磁盘区或首个收藏夹。目标路径不可用时，界面会显示读取错误，用户可以改选其他磁盘。

## 4. 文件浏览

### 4.1 磁盘与目录

- Windows 下枚举盘符 `A:` 至 `Z:`。
- 当前仅列出固定磁盘和可移动磁盘。
- 文件夹始终排在媒体文件之前。
- 同一类型按名称进行不区分大小写排序。
- 默认同时识别 Windows 隐藏属性和以 `.` 开头的隐藏文件。
- 默认不显示隐藏内容，可在设置中开启。
- 文件区支持高密度列表和网格展示，工具栏图标或手柄选择键可切换，选择结果会持久化。
- 从子目录返回父目录时，会重新选中刚离开的子目录并滚动到可见位置，不会跳回列表顶部。

### 4.2 收藏夹

- 在文件浏览页按顶部键可收藏或取消收藏当前目录。
- 收藏夹显示在磁盘区下方。
- 收藏操作只保存路径，不复制或扫描目录内容。
- 每个收藏项均有独立移除按钮；即使原文件夹已删除或磁盘已断开，也可直接移除。
- 手柄聚焦收藏项时，顶部键移除该收藏；聚焦文件区或磁盘项时，顶部键收藏或取消收藏当前目录。
- 可以将首个收藏夹设为应用启动入口。

### 4.3 记住位置

每次成功进入目录后，应用会保存该路径。下次启动选择“上次位置”时，会先检查目录是否仍然存在，再决定是否恢复。

### 4.4 退出与系统关机

- 左侧设置按钮下方依次提供“退出应用”和“系统关机”。
- 两个动作都必须持续按住确认键或屏幕按钮 1.8 秒，短按不会生效。
- 按住时按钮背景从左到右填充，直观显示触发进度。
- 在进度完成前松开、移出按钮或切换导航会立即取消。
- “退出应用”只关闭 CouchAxis；“系统关机”请求 Windows 立即正常关机，不强制结束阻止关机的程序。

### 4.5 应用程序绑定

- 左侧“应用程序”区域提供“绑定应用程序”入口。
- 选择界面完全由 CouchAxis 绘制，可使用手柄浏览磁盘和文件夹，不调用 Windows 文件选择窗口。
- 选择器只展示文件夹和 `.exe` 文件；确认 `.exe` 后，程序名和完整路径会保存到侧栏。
- 确认侧栏中的程序即可启动；绑定只保存快捷入口，不复制或修改目标文件。
- 目标程序要求管理员权限时，Windows 会显示标准 UAC 确认提示。
- 每个应用入口均有独立移除按钮；手柄聚焦该入口时也可按顶部键移除。
- 如果目标文件已移动、删除或无法启动，CouchAxis 会显示短暂错误提示，绑定仍保留以便用户手动移除。

## 5. 文件格式

下表表示“文件会被 CouchAxis 识别并显示”。实际解码能力仍取决于当前 Windows WebView2 媒体栈。

| 类型 | 可识别扩展名 |
| --- | --- |
| 视频 | MP4、MKV、AVI、MOV、FLV、WMV、M4V、WEBM、MPEG、MPG、TS、M2TS |
| 音频 | MP3、FLAC、WAV、AAC、M4A、OGG、OPUS、WMA、AIFF、AIF、ALAC |
| 图片 | JPG、JPEG、PNG、WEBP、GIF、BMP、AVIF、TIF、TIFF |
| 字幕 | SRT、ASS、SSA |

注意：

- “已识别”不等于“当前系统一定能解码”。
- MP4、WebM 和常见音频通常由 WebView2 直接播放。
- MKV、AVI、FLV、WMV、部分无损音频和 TIFF 的可播放或可显示程度取决于系统编码器。
- 计划中的 libmpv 后端尚未接入，因此当前版本不能宣称全格式稳定播放。

## 6. 视频播放

### 6.1 基础控制

- 播放、暂停。
- 向前或向后跳转 10 秒。
- 音量升降和静音。
- 进度条拖动。
- 全屏切换。
- 根据视频元数据保持原始宽高比，窗口与全屏切换期间不拉伸画面。
- 关闭播放器并返回原目录。

### 6.2 播放倍速

右摇杆水平移动逐级切换速度：

`0.5x`、`0.75x`、`1x`、`1.25x`、`1.5x`、`2x`、`2.5x`、`3x`、`4x`

界面中的速度数值按钮可恢复 `1x`。

在系统全屏或视频专注模式中调节音量、静音或播放速度时，画面上方会显示约 1.4 秒的状态提示。音量提示同时显示百分比与进度条，倍速提示显示当前速度；提示不会中断播放或遮挡底部字幕。

### 6.3 最近播放进度

- 视频播放达到 5 秒后，CouchAxis 每 10 秒、暂停以及退出播放器时记录当前位置。
- 重新打开同一视频时自动跳转到记录位置，无需确认弹窗。
- 只保留最近更新的三个不同视频，打开较早的视频后会将其移到最近位置。
- 距离结尾不足 15 秒或已经播放结束的视频视为完成，自动删除该视频的续播记录。
- 无法取得有效总时长、进度不足 5 秒或源文件已不可用时不会强行跳转。

### 6.4 字幕

- 打开视频时，自动查找同目录、文件主名完全相同的字幕。
- 自动匹配优先级为 SRT、ASS、SSA。
- 示例：`Movie.mkv` 可以自动匹配 `Movie.srt`，不会自动匹配 `Movie.zh-CN.srt`。
- 手动字幕选择器默认打开视频所在目录，不调用 Windows 文件选择窗口。
- 字幕选择器支持进入目录、返回父目录、选择字幕和“无字幕”。
- 选择“无字幕”会清空当前字幕。
- 字幕开关可以临时显示或隐藏已载入字幕。
- 字幕字号在设置页选择“较小 / 标准 / 较大”，普通播放和专注模式共用该设置。
- 播放与全屏切换期间持续校准字幕时间；同一时刻存在多条字幕时全部显示。
- 长字幕允许自动换行，避免在屏幕边缘被截断。
- 支持 UTF-8、带 BOM 的 UTF-8、UTF-16 LE 和 UTF-16 BE 文本。
- 单个字幕文件上限为 10 MB。

ASS/SSA 当前解析 `Dialogue:` 时间和文本，移除样式标签后显示纯文本；复杂排版、字体、动画和特效不会被完整还原。

### 6.5 视频截图

- 同时按左右肩键截取当前视频画面。
- 截图包含当前显示的字幕文本。
- 输出格式为 PNG。
- 文件名包括视频名、日期时间和播放位置。
- 重名时自动追加序号，不覆盖已有截图。
- 截图目录可在设置中选择；默认使用系统图片目录下的 `CouchAxis Screenshots`。

### 6.6 视频专注模式

- 按 `R3` 进入专注模式，再按一次 `R3` 退出。
- 进入时隐藏顶部信息栏和底部控制栏，并进入系统全屏。
- 播放暂停、跳转、音量、倍速、字幕、截图和帮助仍可使用。
- 字幕在专注模式下靠近画面底部显示。
- 直接关闭视频时会恢复由专注模式开启的系统全屏。

## 7. 音乐播放

### 7.1 播放队列

打开歌曲时，以当前浏览目录为根目录，递归收集该目录及其子目录中的所有音乐文件：

- 不跟随符号链接，避免循环目录。
- 无权限访问的非根子目录会被跳过。
- 是否包含隐藏音乐由“显示隐藏文件”设置决定。
- 队列按完整路径排序。
- 可以打开队列并直接选择歌曲。

### 7.2 播放模式

- 顺序：播放结束后进入下一首，队尾回到队首。
- 随机：切换时随机选择其他歌曲；队列只有一首时保持当前歌曲。
- 单曲循环：播放结束后从当前歌曲开头重新播放。

播放模式保存在浏览器本地存储中，下次启动继续使用。

### 7.3 元数据、封面和歌词

- 读取歌曲标题、艺术家、专辑、歌词和内置封面。
- 优先使用标记为正面封面的内置图片。
- 没有内置封面或封面读取失败时，显示统一默认封面。
- 不会使用文件夹第一张图片代替封面，避免歌曲与封面错配。
- 内置封面读取上限为 16 MB。
- 支持普通歌词、LRC 风格时间标签和 MP3 的同步歌词帧。
- 有时间标签时按时间滚动；无时间标签时按播放进度估算当前行。

### 7.4 频谱

- 使用 Web Audio API 的频率分析节点生成实时频谱。
- 开启频谱时，上半部分显示频谱，下半部分只显示当前附近两句歌词。
- 关闭频谱时恢复完整歌词滚动。
- 浏览器或系统不允许创建音频分析节点时，频谱会自动停用，不影响普通播放。

### 7.5 黑屏播放

- 按 `R3` 进入黑屏播放。
- 黑屏覆盖整个应用并尽量进入全屏。
- 任意手柄输入、键盘输入或鼠标点击退出黑屏。
- 用于电视熄屏式听歌，不停止当前音频。

## 8. 图片查看

### 8.1 默认显示

- 图片首次打开时按窗口最佳比例完整显示。
- 图片在可用区域内水平和垂直居中。
- 窗口尺寸变化后重新计算适应比例。
- 支持顺时针 90 度旋转和恢复默认视图。

### 8.2 缩放和平移

- 按住左扳机持续缩小，松开停止。
- 按住右扳机持续放大，松开停止。
- 缩放范围为相对适应窗口比例的 `50%` 至 `800%`。
- 图片放大超出视口后，使用右摇杆四向平移。
- 鼠标用户可使用滚轮缩放、拖动平移和双击重置。
- 平移位置会被限制在图片边界内，不会把整张图片拖离视口。

### 8.3 比例锁定与漫画起点

- 按选择键锁定或解除锁定当前缩放比例。
- 未锁定时，切换图片会恢复适应窗口比例。
- 锁定时，切换图片保留相同的相对缩放比例。
- 比例锁定且放大超过 `100%` 时，新图片从顶部开始显示。
- 漫画起点可在设置中选择左上角或右上角。
- 该行为适合纵向漫画或需要从页顶开始阅读的图片序列。

### 8.4 图片专注模式

- 按 `R3` 进入，再按一次 `R3` 退出。
- 隐藏顶部信息栏和底部工具栏，并进入系统全屏。
- 切图、缩放、平移、旋转、重置、比例锁定和帮助保持可用。
- 关闭图片时自动退出由专注模式开启的全屏。

### 10.2 全局约定

- 左摇杆和方向键负责主要导航。
- 同时按左右扳机显示或关闭当前页面的手柄说明。
- 页面说明根据文件浏览、设置、视频、音乐、图片、字幕和目录选择器分别生成。
- 方向输入首次触发后等待约 360 毫秒开始连发，之后约每 110 毫秒重复。
- 左右肩键和左右扳机组合使用 80 毫秒保护窗口，避免组合键同时误触单键动作。

## 12. 数据与隐私

- 不联网获取媒体信息。
- 不上传文件名、路径、封面、歌词、字幕或截图。
- 不建立媒体数据库。
- 浏览器开发模式只使用固定演示数据，不访问真实磁盘。
- 桌面模式通过 Tauri IPC 读取本机目录和媒体元数据。

## 13. 当前限制

- 当前媒体播放基于 WebView2 的 HTML `video` / `audio` 元素，不是 libmpv。
- 当前手柄输入基于浏览器 Gamepad API，不是 SDL2。
- 不同手柄驱动是否按标准布局上报，会影响按键识别。
- ASS/SSA 仅保留时间与文本，不渲染复杂样式和动画。
- 截图依赖当前视频帧可以绘制到 Canvas；无法读取当前帧时会提示截图不可用。
- 音频频谱依赖 Web Audio API，受系统和媒体解码能力影响。
- 当前不保存视频播放进度、图片缩放状态或单首歌曲播放位置。

## 14. 建议验收清单

### 文件系统

- 固定磁盘和 U 盘均可选择。
- 隐藏文件开关生效。
- 收藏夹可添加、取消和重新进入。
- 重启后上次路径和设置仍存在。
- 退出与系统关机均只在长按满 1.8 秒后触发，提前松开时进度清零且不执行。

### 视频

- 播放、暂停、跳转、音量和倍速可用。
- 同名字幕自动载入，手动字幕和“无字幕”可选。
- 左右肩键组合截图成功且不同时触发跳转。
- `R3` 可进入和退出专注模式，其他播放操作仍正常。

### 音乐

- 队列包含子目录歌曲且不包含非音频文件。
- 顺序、随机和单曲循环行为正确。
- 内置封面和歌词可显示；无封面时显示默认封面。
- 频谱与两句歌词布局正确。
- 黑屏后任意输入可以退出。

### 图片

- 默认完整居中显示图片。
- 扳机按住连续缩放、松开停止。
- 放大后右摇杆可以平移。
- 比例锁定后切图保持缩放。
- 漫画起点设置为左上或右上时行为正确。
- `R3` 可进入和退出专注模式，其他看图操作仍正常。
